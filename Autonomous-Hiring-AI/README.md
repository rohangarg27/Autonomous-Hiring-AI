# Autonomous Hiring Pipeline Using AI Agents

An end-to-end, multi-agent AI system that automates resume screening, interview question generation, bias auditing, and explainable hiring decisions.

## Features
- Semantic resume screening using transformer embeddings
- Skill inference with hybrid symbolic + neural reasoning
- Role-aware interview question generation
- Bias auditing via counterfactual masking
- Explainable hiring decision reasoning
- Modular multi-agent architecture
